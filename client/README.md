# ReelMatch — client (Expo + React Native)

```bash
cp .env.example .env      # pune IP-ul laptopului în EXPO_PUBLIC_API_URL
npm install
npx expo start
```

Structură: `src/app` (rute Expo Router), `src/components`, `src/services` (apeluri API),
`src/hooks` (React Query), `src/store` (Zustand auth), `src/types`, `src/constants`.
